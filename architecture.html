Front-End Phases

The front-end is machine-independent and processes the source text:

  • Lexical Analysis: Converts character sequences into typed tokens (NUMBER, PLUS, MINUS, LPAREN, etc.).
  • Syntax Analysis: Parses tokens via Context-Free Grammar (CFG) rules into an Abstract Syntax Tree (AST).
  • Semantic Analysis: Type propagation (int vs float promotion) and pre-runtime division by zero verification.

Back-End Phases

The back-end takes the validated AST and prepares it for evaluation:

  • Intermediate Code Generation (ICG): Emits linear Three-Address Code with temporaries (t1, t2, ...).
  • Quadruple Records: Structured 4-tuples [Operator, Argument 1, Argument 2, Result].
  • Virtual Machine / Executor: Executes TAC line by line with memory registers.

Formal Grammar & Precedence Climbing

// Context-Free Grammar (CFG)
Expr   → Term (( '+' | '-' ) Term)*
Term   → Power (( '*' | '/' ) Power)*
Power  → Factor ( '^' Power )?     // Right-associative exponentiation
Factor → '+' Factor | '-' Factor | NUMBER | '(' Expr ')'
